# 🦠 Phage — Bug Reports & Feature Requests

This is the **public feedback repo** for [Phage](https://slonto.com/happytodev/digitaux/phage), the local PHP development environment.

Phage itself is [sponsorware](https://github.com/sponsors/happytodev): the source code is sponsor-only until we reach **50 sponsors**, then it becomes 100% open source (MIT). But **bug reports are open to everyone** — right here.

## 🐛 Report a bug

[Open a bug report →](../../issues/new?template=bug_report.yml) — please include:

- Your OS (macOS / Windows / Linux + version)
- Phage version (`phage version` or About page)
- Steps to reproduce
- What you expected vs what happened

> 🧪 Phage is still in beta, so bugs happen. It already hosts real local sites every day — your report makes the next release more stable. Thanks!

## 💡 Suggest a feature

[Open a feature request →](../../issues/new?template=feature_request.yml) — describe your use case, not just the solution.
